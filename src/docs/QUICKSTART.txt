TRY IT FIRST (optional) — no Garmin account needed
────────────────────────────────────────────────────
A synthetic 180-day demo archive (fictional data, clearly marked as
such) lets you explore dashboards, Chat and the MCP server before
connecting your own account.

1. Unzip demo_archive.zip
   -> src/support-tools/demo-export/demo_archive.zip (GitHub)
   Note the path to the extracted folder.
2. Settings tab -> set Data folder to that path -> "Save Settings"
3. Optional: Settings tab -> Dashboards -> "Create Dashboards" to generate
   the dashboards (or try "Custom Dashboard" / "Encrypted Dashboards"
   right below it)
4. Optional: MCP Server tab -> configure and start the server, or
   open the Chat tab, to query the demo archive directly

Ready to connect your real account? Continue below.

FIRST-TIME SETUP
────────────────
1. Open the Settings tab
2. Enter your Garmin email and password
3. Set the Data folder
   (where the archive will be stored)
4. Context: paste a Google Maps URL of your location
   The app extracts the coordinates automatically
   -> Open Google Maps -> search your location ->
      copy the URL from the address bar -> paste it
      -> click "Set location"
5. Click "Save Settings"

RUN YOUR FIRST SYNC
────────────────────
- Click "Daily Sync" (big button at the top)
- Downloads recent days including weather and pollen data
- Green dot top-left = connection successful
- Progress appears in the log at the bottom

IMPORT YOUR FULL HISTORY (recommended)
────────────────────────────────────────
Garmin only provides ~120 days at full resolution via API.
For the complete history: request a GDPR export from Garmin
-> https://www.garmin.com/en-US/account/datamanagement/
This can take several days — request it now.
Import: Settings -> Data Collection -> "Bulk Import"

OPEN DASHBOARDS
───────────────
Home tab: click the Dashboard dropdown (v) -> select a dashboard
Files tab: Excel overview (v)

BACKUP
──────
Settings -> set Mirror target -> "Export to Mirror"

DISCOVER MORE DATA (optional)
──────────────────────────────
Settings -> Data Collection -> "API Scan" checks if your account
provides additional health data (e.g. from a connected smart scale).
-> Details: USER_GUIDE.txt, "API Capability Scan"
